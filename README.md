# 🏠 Apna Ghar

A full-stack home rental web application  where users can list, discover, and book unique stays across different landscapes.

## ✨ Features

- 🔐 User authentication (signup, login, logout) with Passport.js
- 🏡 Create, edit, and delete property listings
- 🖼️ Image uploads via Cloudinary
- 🗺️ Interactive maps with TomTom API
- 💬 Real-time messaging between guests and owners using Socket.io
- ⭐ Review and rating system for listings
- 🔍 Search listings by name
- 🏷️ Filter listings by category (Mountains, Beach, Desert, and more)
- 📱 Fully responsive design with Bootstrap

## 🛠️ Tech Stack

| Frontend | Backend | Database | Other |
|---|---|---|---|
| EJS, Bootstrap | Node.js, Express | MongoDB, Mongoose | Socket.io |
| Font Awesome | Passport.js | Cloudinary | TomTom Maps API |

## 🚀 Getting Started

### Prerequisites
- Node.js
- MongoDB
- Cloudinary account
- TomTom API key
